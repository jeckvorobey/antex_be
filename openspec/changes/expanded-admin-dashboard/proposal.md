## Why

Текущий `/api/admin/summary` отдаёт только число заявок за день, общее число пользователей и три курса. Оператор не видит очередь проблемных заявок, динамику за сегодня, обороты по валютам и полный набор курсов, поэтому вынужден собирать картину по нескольким экранам.

## What Changes

- Расширяется admin summary с сохранением существующих полей.
- Добавляются точные метрики пользователей и заявок за текущий локальный день.
- Добавляется отдельное время последней пользовательской активности.
- Добавляется очередь заявок, требующих внимания.
- Добавляются обороты завершённых заявок отдельно по каждой валюте.
- Добавляется полный читаемый список настроенных публичных курсов.
- Для каждого курса добавляется базовая цена рядом с итоговым клиентским курсом.

## Capabilities

### New Capabilities

- `admin-operational-dashboard-api`: единая операционная сводка для admin dashboard.
- `user-last-activity`: достоверная фиксация успешного входа пользователя в Mini App.

### Modified Capabilities

- `admin-summary-api`: существующий MVP-контракт расширяется без удаления старых полей.
