# Каталог Telegram-сообщений AntEx

Этот документ фиксирует пользовательский copy и presentation contract. Общие правила разработки
определяет `../../antex_rules.md`.

## Общий формат

Системная карточка строится как `категория → результат/вопрос → факты → одно действие`.
Rich HTML использует `footer`, `h2`, короткий `p` и двухколоночную таблицу фактов. Regular HTML
fallback сохраняет те же факты вертикальными строками. Динамические значения экранируются в
`app.telegram.presentation.escaping`; кнопки всегда передаются через `reply_markup`.

## Пользовательский путь

| Событие | Семейство | RU/EN copy contract | CTA |
|---|---|---|---|
| Бот недоступен | status | Бот временно недоступен; повторить позже | — |
| `/start` | hero | Приветствие, круглосуточный приём и выбор канала | Telegram / Mini App |
| Страна | selection | `Новая заявка · Страна` / `New order · Country` | Страна |
| Услуга | selection | Именованный этап и короткое объяснение способа | Услуга |
| Город | selection | Именованный этап без изменения общего числа шагов | Город |
| Валюта и курс | selection/financial | Именованный этап, доступные направления и курс | Валюта |
| Сумма | input | Именованный этап, валюта и минимальная сумма | Ввести сумму |
| Ошибка суммы/курса | input/status | Причина и повторный ввод без технических деталей | Повторить |
| Проверка | summary | Фактические страна, город, курс, суммы и способ | Подтвердить |
| Вне графика | status | Заявка попадёт в очередь до ближайшего рабочего интервала | Создать / отменить |
| `CREATED` | status | Заявка получена и передана в очередь; обработка ещё не обещается | Мои заявки |
| `PROCESSING` | status/summary | Менеджер готов; первое сообщение открывает диалог | Написать менеджеру |
| `COMPLETED` | status/financial | Благодарность; Telegram video note даёт `$5` к следующему обмену | Оставить отзыв |
| `CANCELLED` | status | Работа по заявке остановлена | Главное меню |
| Реферальное начисление/списание | financial | Знак, сумма ATXG и публичный номер заявки | — |
| ATXG credit/debit | financial | Знак, сумма, безопасно показанное основание | — |
| Мои заявки | summary | Пустой список либо фактические параметры заявок | Навигация |

## Менеджерский путь (RU-only)

| Событие | Семейство | Copy contract | CTA |
|---|---|---|---|
| `/start` | manager/hero | Рабочее место, новые заявки и приложение | Новые заявки |
| Список/пустой список | manager/summary | Только актуальные `CREATED` заявки | Открыть заявку |
| Карточка заявки | manager/summary | Статус, клиент и фактические параметры | Взять/отменить |
| Handoff/reminder | manager/status | Факт доставки без ложного подтверждения | Напомнить |
| Cancel/complete | manager/status | Итог операции и доступные действия | Открыть чат |
| Site lead | manager/summary | Контакт, источник и сокращённое при необходимости сообщение | Связаться |
| Callback alerts | plain alert | Краткий исход действия без Rich layout | — |

## Источники и ограничения

- Клиентские RU/EN ключи: `locale/{ru,en}/bot.ftl`.
- Manager alerts: RU namespace `manager-alert-*`.
- Администраторская рассылка — authored content, не системный copy; транспорт принимает только
  ограниченный по длине payload и не обрезает его молча.
- Любое новое сообщение обязано иметь Rich и regular HTML представления с одинаковыми
  facts/placeholders/CTA и тест на оба transport.
